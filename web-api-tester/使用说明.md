# Web API 测试工具使用说明

## 项目介绍

这是一个基于Web的API接口测试工具，提供了两个版本：

1. **基础版** (`index.html`)：简单易用，适合快速测试API
2. **高级版** (`advanced.html`)：功能丰富，支持历史记录、环境变量、请求保存等高级功能

## 登录和认证

### 登录功能
- 工具现已支持用户登录认证，确保数据安全
- 首次访问会自动跳转到登录页面
- 登录后会在页面右上角显示用户信息和登出按钮

### 默认账号
系统提供两个演示账号：

1. **管理员账号**
   - 用户名：`admin`
   - 密码：`admin123`

2. **普通用户账号**
   - 用户名：`user`
   - 密码：`user123`

### 登录特性
- 支持"记住我"功能，勾选后7天内无需重新登录
- 未勾选"记住我"时，登录状态保持24小时
- 支持密码显示/隐藏切换
- 点击演示账号可快速填充登录信息

## 快速开始

### 方法一：使用启动脚本（推荐）

#### Linux/Mac用户：
```bash
cd web-api-tester
./start.sh
```

#### Windows用户：
```batch
cd web-api-tester
start.bat
```

启动脚本会自动：
- 启动测试API服务器（端口3001）
- 启动Web测试工具服务器（端口3000）
- 显示访问地址

### 方法二：手动启动

1. 启动Web服务器：
```bash
cd web-api-tester
node server.js
```

2. （可选）启动测试API服务器：
```bash
node test-example.js
```

3. 在浏览器中访问：
- 基础版：http://localhost:3000/index.html
- 高级版：http://localhost:3000/advanced.html

## 基础版功能介绍

### 主要功能
- 支持所有常见的HTTP方法（GET、POST、PUT、DELETE等）
- 自定义请求头
- 多种请求体格式（JSON、Form、XML等）
- 支持多种认证方式（Bearer Token、Basic Auth、API Key）
- 实时显示响应结果

### 使用步骤
1. 输入API地址
2. 选择HTTP方法
3. 配置请求头、请求体、认证信息（如需要）
4. 点击"发送请求"
5. 查看响应结果

## 高级版功能介绍

### 额外功能
- **请求历史**：自动保存最近50条请求记录
- **环境变量**：支持使用 `{{变量名}}` 语法替换URL、请求头、请求体中的内容
- **请求保存**：可以保存常用的请求配置
- **数据导入/导出**：支持导出和导入所有数据（历史、保存的请求、环境变量）
- **Query参数**：独立的Query参数配置界面

### 环境变量使用示例

1. 点击"环境变量"按钮，设置变量：
```json
{
  "apiUrl": "http://localhost:3001",
  "token": "my-secret-token",
  "userId": "123"
}
```

2. 在请求中使用变量：
- URL: `{{apiUrl}}/api/users/{{userId}}`
- Header值: `Bearer {{token}}`

### 历史记录功能
- 自动保存每次请求的详细信息
- 点击历史记录可以快速恢复请求配置
- 支持清空历史记录

### 数据管理
- **导出数据**：将所有数据导出为JSON文件
- **导入数据**：从JSON文件导入数据
- 数据包括：请求历史、保存的请求、环境变量

## 测试API端点

启动测试API服务器后，可以使用以下端点进行测试：

### 1. 简单GET请求
```
GET http://localhost:3001/api/hello
```

### 2. POST请求（Echo）
```
POST http://localhost:3001/api/echo
Body: {"message": "test"}
```

### 3. 带参数的GET请求
```
GET http://localhost:3001/api/users/123
```

### 4. 需要认证的请求
```
GET http://localhost:3001/api/protected
Header: Authorization: Bearer your-token
```

### 5. 错误响应测试
```
GET http://localhost:3001/api/status/500
```

## 常见问题

### 1. CORS跨域问题
如果遇到跨域错误，确保：
- API服务器已设置适当的CORS头
- 使用支持CORS的API进行测试
- 或者使用浏览器插件临时禁用CORS（仅用于开发）

### 2. HTTPS混合内容
从HTTP页面请求HTTPS API可能被浏览器阻止。解决方案：
- 使用HTTPS部署测试工具
- 或者在开发环境使用HTTP API

### 3. 大文件处理
当前版本不支持文件上传，如需测试文件上传API，建议使用Postman等专业工具。
